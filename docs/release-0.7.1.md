# Mic Studio 0.7.1 开发预览 · 备用麦克风与排除名单

- 在设备或设置页的“断线恢复 → 备用与排除”配置高级功能。断线恢复和备用切换默认关闭，最多保存 8 个明确选择的备用麦克风及其顺序、采样率和声道数。
- 当前麦克风断开后，按顺序验证已配置的可用备用。CABLE、已确认的耳机监听和格式必须符合本次线路授权，连接稳定至少 1 秒后尝试。已进入等待且仍就绪的备用会完成该次等待。原设备返回时保持当前输入，可手动切回。
- 新增最多 64 项麦克风排除名单，作用于自动首次选择、恢复和备用切换。手动选择与开始仍可使用已排除设备，排除的当前输入不会建立自动恢复授权。
- 备用切换成功后更新并记住当前输入，显示窗口与托盘提示，解除原设备的音量锁定。备用使用当前声音设置，需锁定新设备音量时重新开启。
- 配置变化会取消待恢复，当前正在运行的线路可按新配置重新授权。停止、锁屏或休眠、文件回放和啸叫保护继续撤销恢复授权。每次断线一次尝试、任意 60 秒最多 3 次的限制覆盖备用切换，按住说话需重新按键，录音和文件回放需手动重新开始。

P7 计划中的软件功能已实现开发预览。真实设备拔插、设备重建、休眠唤醒、Discord 接收和长期使用仍待实机验收。
