# Mic Studio 0.3.0 预览版 · 日常后台使用

P2 阶段交付：让 Mic Studio 可以一直在后台待命，记住上次的参数，并支持简体中文 / English。

## 后台与托盘

- 点击窗口关闭按钮默认收进托盘，当前本地处理和虚拟线路发送不中断。设置页仍可关闭“关闭到托盘”。
- 托盘菜单：打开 Mic Studio、暂停处理 / 继续处理、停止全部本地音频、退出。
- 窗口与托盘共用同一份处理状态；托盘菜单的暂停/继续等同于主窗口的开始/停止。
- 只有明确“退出”才停止本地音频、释放设备和移除托盘图标；隐藏到托盘不停止声音。
- 窗口隐藏时发生的启动或保存错误改用托盘通知提示。

## 记忆与迁移

- 工作区升级到 schema 2：参数、设备稳定 ID、EQ/效果、主题、预设、语言、主题色、托盘和登录启动偏好继续本地保存。
- 0.2.x 工作区自动迁移；由于旧版本没有区分“主动关闭托盘”的标记，迁移后默认关闭到托盘。原参数、预设和设备选择不被删除。
- 设置文件损坏时保留副本并读取上次备份，仍不会静默应用音频配置。

## 登录启动

- 设置页“登录 Windows 后启动 Mic Studio”写入当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `MicStudio.Next` 值，命令为带引号的 `MicStudio.exe --minimized`。
- 登录启动进入托盘，不弹出主窗口；`--minimized` 启动只创建托盘入口。
- “登录启动后自动开始处理”是独立选项，默认关闭，且只在登录启动时考虑；手动启动永远不会自动打开麦克风。若没有可用麦克风，自动开始会被跳过并提示。
- 更新或移动便携目录后会按当前程序路径修复启动项；卸载清理 Mic Studio 自己创建的启动项，不触碰其他程序的值。

## 中文 / English

- 设置页可即时切换简体中文 / English，语言选择写入工作区并在下次启动恢复。
- 切换语言只重建界面，不停止音频，不改变增益、EQ、效果、主题或设备。
- 覆盖主窗口七个页面、导航、顶部操作、按钮、状态、提示、参数错误、确认对话框、托盘菜单和脱敏诊断摘要。
- 内置预设名称/说明、创意主题、八段频率名称和“无 / 自定义 / 默认”状态随语言显示；个人预设保留用户输入的原文。
- Windows 设备名称、Equalizer APO 工具自身的输出、VB-Cable 官方安装器界面和底层系统错误仍按原有语言显示，不伪装成已翻译。

## 验证

- 43 项实际 WPF 控件与路由事件检查，覆盖默认托盘、P1 工作区迁移、启动偏好持久化、语言按钮、英文导航、托盘菜单与关闭到托盘。
- 27 种中文布局和 27 种英文布局（1280×820、900×600、600×500，七个页面及展开高级功能），无横向溢出且滚动可达。
- 英文界面逐页检查 TextBlock、按钮、复选框、Expander 和外壳文本，未翻译汉字计数为 0。
- Core 测试新增启动命令的引号、最小化参数、路径和恶意字符校验，共 38 项通过。
- 真实当前用户启动项写入/移除自测通过，测试后未留下 `MicStudio.Next` 值；未执行安装器或更改驱动。
