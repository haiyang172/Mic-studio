# Mic Studio 0.2.1 预览版 · 自动连接虚拟线路

修复已安装 VB-CABLE 却一直提示“发送端或接收端未就绪”的问题：驱动重装会改变设备编号，旧版只在没有保存选择时自动选择，因此失效的旧编号无法恢复。

- 启动、刷新设备、设备出现以及开始处理前，自动匹配有效的 CABLE 收发端并修复旧选择。
- 单条可用线路无需手动选择；多条线路保留可选的高级选择，显示准确的接收端名称。
- 不将不同 CABLE 的收发端混用；缺失、停用、不配对或重复端点分别提示原因。
- 保留用户选择的实体麦克风；自动匹配不自动开麦、修改系统默认设备或重启正在运行的用户程序。

验证：39 项 WindowsAudio 合成/空闲检查、32 项 WPF 控件检查及 27 种布局通过。本机只读验证可从失效编号自动匹配现有线路；未开启实体麦克风或安装驱动。

下载 `MicStudio.Setup.exe` 或 `MicStudio-win-x64.zip`。更新后点击“开始处理”即可自动使用匹配的虚拟线路；接收软件输入选择设备页显示的名称。
