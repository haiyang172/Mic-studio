更新：2026-11-05（Australia/Sydney）。当前为 0.6.1 简洁界面开发预览；P6 后台控制已在 0.6.0 实现。

本计划承接[原升级计划](upgrade-plan.md)，根据同类软件调研安排后续工作。P6 的后台快捷键、按住说话和可选音量锁定已实现；P7～P12 尚未实施。版本号是里程碑，实际发布可以拆分，不承诺固定日历工期。

## 2. 使用原则

- 主页面保留设备、增益、电平、预设、静音和开始/停止。常用功能一两步完成。
- 普通模式采用“模式＋强度”；详细音频参数、线路、插件和混音放进默认收起的高级功能。
- 默认恢复上次参数，手动启动软件不自动开麦；快捷键和新功能遵守同一规则。
- 保留已选择的麦克风。备用设备切换必须明确选择并启用；默认不自动换成其他麦克风。
- 实时调音、自动保存、保存主题保持各自含义；恢复默认保留设备、语言和个人资料。
- 继续使用 A2 品牌。用户已确认参考 Krisp/Broadcast 的简洁主页、Voicemod 式主题卡片与折叠高级功能；0.6.1 整理现有功能。Soundpad 式音效板保留到 P9，不把视觉参考当作功能已实现。

P6→P7→P8 为第一轮重点，P6 开发预览完成后先根据真实使用反馈修正，再推进 P7；之后加入娱乐和更重的算法。自研 APO 与质量验收作为并行工作线，不等待所有新功能做完才处理。局域网音频、手机遥控、在线声音社区作为候选功能，暂不列入首轮承诺。

0.6.1 的界面整理保持既有处理和发送语义：处理方式移至“设备 → 高级连接”，主页系统麦克风静音、校准与录音/A/B 收进高级功能。主题选择不自动开麦，后台快捷键/PTT/音量锁定沿用 0.6.0 的启用规则。

## 4. 每一阶段的具体范围

### P6：快捷操作与音量协调

0.6.0 开发预览已实现：

- 后台快捷键默认关闭。开启后可自定义本地发送静音、效果开关、下一个预设、增益 ±1 dB、停止本地处理和按住说话；提供冲突/保留键提示、清除与恢复默认。第一版以本地/CABLE 路线为范围，停止时修改设置不启动音频。
- 按住说话只控制已开始处理的本地/CABLE 麦克风发送，不改变耳机监听、DSP 电平或录音；Windows 端点静音仍是独立操作。松开按键或必需的修饰键即关闭，失焦、会话/电源变化与心跳超时后要求松开再按；快捷键未就绪时保持不发送。
- 音量锁定默认关闭，只针对明确选择并启用的麦克风端点。开启和恢复时读取当前系统音量，不套用旧音量；用户自己的滑条可更新目标。外部改动恢复有节流，持续争抢或断线时暂停并提示；换麦克风需重新开启，退出后停止干预。
- 快捷键、按住说话、发送静音及锁定偏好写入本地工作区；音量锁定绑定精确端点，重启只恢复同一已连接麦克风。不开启新麦克风、不修改系统默认设备或 Windows 端点静音。

验证范围：自动检查使用合成音频、可控按键状态与虚拟音量端点；隔离界面检查不注册真实快捷键、不写实际麦克风音量、不启动音频。真实后台按键、睡眠唤醒、设备拔插、Discord 外部接收和一小时使用仍待实际验收，不宣称拥有 Windows 音量的独占控制权。完整 P3/P4/P5 的未完成条件不变。

### P7：声音线路图与可靠恢复

交付：

- 显示“麦克风 → 本地处理 → 虚拟线路 → 接收软件”的连接与可测状态，并提供简洁的故障解释和对应入口。
- 分别显示输入/处理后电平、静音、设备断开、参考未就绪、缓冲异常和反馈风险；脱敏导出诊断。
- 可选“同一设备重新接入后恢复”，仅恢复之前正在运行的明确选择；主动停止后不自动恢复。备用设备与排除名单放高级功能。

验收：区分设备存在、本地有信号、已发送与外部应用实际收到。音频会话存在不证明 Discord 已选对输入；无法证明时显示待确认。设备重建、反复拔插、睡眠唤醒和 CABLE 两端不完整均有验证，不跨线路或误换麦克风。算法/队列时间不冒充实测端到端延迟。

### P8：语音修饰与循环调音

交付：

- 去齿音：普通界面提供强度，细节阈值和频段放高级功能。
- 在现有讲话增益建议基础上增加短引导：正常讲话、查看建议、试听后确认；持续自动增益作为后续评估项，与一次测量建议区分。
- 在已有录音和离线 A/B 基础上，增加“循环播放同一段录音时实时调参数”，减少重复讲话。先沿用现有 RMS 配平方式，响度标准升级另行验证。

验收：去齿音有效同时保留辅音、轻声和尾音；关闭/开启可对比。试听默认明确选择耳机，试音不自动送进通话，不与实时麦克风混播；停止状态试音不自动开麦。新增效果先覆盖本地/CABLE，不自动声称原生 APO 同时支持。

### P9：音效板

交付：

- 导入本地音效、命名/收藏/分类、快捷键播放、一键停止全部。
- 独立设置监听与发送音量，明确选择“仅自己听／发送／两者”；首次导入和预览默认只监听。
- 初版按单音效播放，再明确是否支持叠加/排队；可选讲话时降低音效音量。PTT 初版只控制实时讲话，发送音效是独立的明确操作。

验收：重复按键、连续播放、停止/退出、切换设备和无效文件均可恢复。音效在人声前级清理之后混入，最终限幅和啸叫保护覆盖混音输出；另测音乐/长音造成的误触发。素材不默认采集用户麦克风或系统声音。

### P10：自然变声

交付：

- 引入能分别处理音高与共振峰的方案，升级现有延迟线变调预览。
- 普通界面仍选萝莉、氢气、低沉等主题并调强度；独立音高/共振峰、干湿比例放高级功能。
- 允许保存和切换自定义声音，兼容旧主题参数；原算法保留为可回退方案。

验收：使用相同真实语音检查男/女声、清辅音、气声、长句、快速切主题与同时说话，记录音质、处理耗时和延迟。预设名称及合成音高变化不代替自然听感验收；选择方案前核对算法许可和实时适用性。

### P11：智能人声清理

交付：

- 分开评估底噪抑制、主说话人隔离、播放参考 AEC 和房间去混响，各自有清楚的能力说明。
- 提供效果优先、低负载和自动模式；只有验证后才加入相应 CPU/GPU 后端。
- 明确模型下载、版本、来源/许可、空间占用、离线能力与实际支持的设备条件。

验收：同源语音对比持续噪声、键盘、旁人讲话、外放、混响和双讲；记录 CPU/GPU、内存、延迟及失真。模型缺失或负载过高时有可用回退和明确状态；不把通用降噪称为主说话人识别，不预先承诺适配所有麦克风或完全消除噪声。

### P12：高级效果与混音扩展

先实施 VST3，再实施监听/对外双混音。插件扫描、异常恢复、参数保存、顺序与附加延迟分别验证，不直接把任意第三方插件放进系统 APO 回调。

双混音先定义每条输入到监听/发送的音量、静音和效果范围，再扩展应用音量与更多输出；每条输出有独立电平和最终保护。默认模板只发送用户明确选择的来源，避免把电脑全部声音送入麦克风。高级界面收起，普通模式保留单一路线。

## 5. 并行工作线

| 工作线 | 必需工作 | 完成证据 |
| --- | --- | --- |
| P4 自研 APO | 可信签名方案、真实录音端点绑定、Windows 加载、增益/EQ 响应、非目标端点隔离、异常透传、安装/更新/还原 | 系统加载与真实声音测量、备份/恢复和目标应用记录；没有证据继续标为开发预览 |
| 长期稳定性 | 一小时连续处理、设备拔插、休眠唤醒、采样率变化、频繁调参、CPU/内存与中断情况 | 可复验记录，测量范围明确；先采集基线再确定性能目标 |
| UI 与发行 | 实际 100%～200% DPI/跨屏/高对比、键盘操作、中英文、安装/升级/卸载、用户数据保留 | 真实操作与包检查记录；沿用 A2，保持简洁布局 |
| 应用更新 | 软件内检查版本、显示变更、下载校验、引导更新与失败恢复；驱动更新独立管理 | 不打断正在处理的音频，保留设置/主题，取消和失败可恢复；稳定/预览渠道清楚区分 |

自研 APO 和自有虚拟麦克风驱动是不同工作包；是否替换 VB-CABLE 需要另行立项，不能因为完成 APO 就视为已拥有虚拟输入设备。

## 6. 每阶段交付与稳定版条件

每一阶段交付：可运行预览、变更说明、相关自动检查、真实使用验证记录，以及设置迁移/回退说明。检查按改动范围安排，不用增加与实现重复的测试来代替听感或系统验收。

进入 1.0 稳定版前，至少满足：

1. 常用操作、后台行为、实时调音和个人设置迁移稳定，关键问题有恢复路径。
2. 语音清理/变声按实际交付范围通过真实讲话验收，效果与资源占用如实说明。
3. 1.0 稳定版必须完成自研 APO 的可信分发、Windows 实际加载、目标端点处理、非目标端点隔离及安装/恢复验收。第三方接入在这些验收通过后再移除。
4. 发行包与更新过程完整、可校验，真实升级/卸载保留个人数据；无未解决的严重音频或数据问题。

**P6：全局快捷键 → PTT → 可选音量锁定**已实现开发预览。后续以真实使用验收结果决定进入 P7 或先修复稳定性问题。
