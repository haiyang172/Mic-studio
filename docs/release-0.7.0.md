# Mic Studio 0.7.0 开发预览 · 声音线路与同设备恢复

- 设备页新增“麦克风 → 本地处理 → 虚拟线路 → 接收软件”。四段分别显示设备连接、实测电平、本地发送状态和接收确认状态。请在接收软件中单独试听。
- 线路状态包含效果关闭、发送静音、等待按住说话、啸叫保护、线路缺失、播放参考和缓冲重置。脱敏诊断导出线路状态代码和计数。
- “同一设备重新接入后恢复”默认关闭，可在设备或设置页启用。恢复使用本次已开始的本地/CABLE 会话，核对原麦克风、CABLE 两端、已确认的耳机监听和采样率、声道数。设备稳定至少 1 秒后才尝试，每次断线一次，任意 60 秒内最多 3 次。
- 主动停止、设备或监听设置变化、锁屏或休眠、啸叫保护和文件回放会取消待恢复。恢复失败、端点变化和格式改变后需手动开始。软件记住开关偏好，每次启动重新建立会话。录音与文件回放需手动重新开始，按住说话需重新按键。

这是首个 P7 开发预览，备用设备和排除名单留在 P7 后续。已完成模拟重连和隔离界面检查。真实拔插、休眠唤醒和 Discord 接收仍待验收。
