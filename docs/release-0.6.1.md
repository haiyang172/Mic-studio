# Mic Studio 0.6.1 开发预览 · 简洁操作与主题卡片

- 按已选定的简洁界面方向整理主页：设备、系统音量、增益、真实电平和一个开始/停止主操作集中显示；Windows 麦克风静音、校准、录音与 A/B 收进默认折叠的高级功能。
- 创意声音和预设库改为可直接选择的主题卡片，选中状态清晰。声音预设的复制、收藏、重命名、删除与导出收进“管理与导出”，保留个人预设、导入及设置记忆。
- 处理方式移至“设备 → 高级连接”；CABLE 自动连接、第三方系统 APO 和自研 APO 开发预览的能力与限制保持原有含义。
- 延续 A2「翡翠流线」图标、中英文、深浅主题、后台快捷键、按住说话、音量锁定和关闭到托盘。界面改版不改变音频算法，不因选主题或展开功能而自动开麦。

主页与基础效果参考简洁设备/效果面板，主题选择采用卡片形式，专业参数按需展开。Soundpad 风格音效板仍安排在 P9，本版没有新增音效板。

完整 Windows DPI、跨显示器、真实音频与 Discord 通话、长期后台运行和安装升级卸载验收继续保留；可信 APO 签名、系统加载与设备响应仍待完成。界面方向选定不代表完整 P3/P4/P5 验收通过。

下载 `MicStudio.Setup.exe` 或 `MicStudio-win-x64.zip`。本包不会注册未签名原生 APO，也不会自动重启系统音频服务。
