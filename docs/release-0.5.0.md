# Mic Studio 0.5.0 开发预览 · 外部回声保护与原生 APO

- 外放回声消除使用电脑播放声作本地参考，支持经过 CABLE 的 Discord 外部监听。开始处理时自动匹配物理播放参考；未就绪会明确显示，不保存或上传播放内容。
- 持续啸叫触发静音保护，效果关闭时仍生效，并清空待播队列。先停止外部回放或改用耳机，再停止并重新开始处理。
- 自研 APO 已有真正的原生 DLL、增益/EQ/限幅、实时参数通道、心跳透传保护和部署预览。设备页与处理方式中可检查开发组件状态。
- 用户选择先交付开发预览：未签名 APO 不自动安装或绑定，可信签名与 Windows 实际音频响应仍待验收，完整 P4 尚未完成。原生路线暂不包含桌面播放参考 AEC。
- 保留现有可用路线与当前图标；已选定的 A2 品牌方案在后续 P5 应用。

外放 AEC 和啸叫保护经过合成信号检查；真实房间、USB 设备时钟、扬声器失真与 Discord 麦克风测试仍需试听，不能保证完全消除回声。外部软件输入需要选择设备页显示的 CABLE Output，选择原始麦克风会绕过本地处理。

下载 `MicStudio.Setup.exe` 或 `MicStudio-win-x64.zip`。建议先使用耳机、较低增益进行试听，再逐步评估外放效果。此安装包不会注册未签名原生 APO，也不会自动重启系统音频服务。
