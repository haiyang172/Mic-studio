## 1. 升级目标与优先级

把 Mic Studio 做成容易上手的麦克风工具：选设备、开始处理、调整声音，常用操作一两步完成。处理过程中改 EQ、增益或主题应立即改变声音；关闭窗口后继续在托盘运行。

优先顺序：

1. 简化操作与实时调音，解决当前最直接的使用问题。
2. 完善设置记忆、托盘、开机启动、中英文和主题管理。
3. 提升真实语音的降噪、回声处理及变声质量。
4. 完成 Mic Studio 自研 Windows APO，替代第三方 Equalizer APO 接入。其技术验证提前进行，避免最后才发现安装或兼容性问题。
5. 按已选定的 A2「翡翠流线」完善图标和 Logo，完成整体打磨和发行验收。

语音清晰、完整和稳定优先于恶搞效果数量。自研 APO 是确定的升级目标，不把已有本地 DSP 改名作为交付。

## 2. 已确定的界面与操作

| 区域 | 计划行为 |
| --- | --- |
| 主页面 | 设备选择、输入音量/增益、真实电平、播放器式开始/停止、当前预设 |
| 开始/停止 | 主操作随状态显示“开始处理”或“停止”；点击开始直接使用当前参数 |
| 运行状态 | 显示“处理中 / 已停止 / 设备不可用”；去掉采集运行计时，采样率和声道移到诊断或高级功能 |
| 顶部操作栏 | 移除“应用、撤销、重做”，只保留“恢复默认” |
| 效果开关 | 代替“旁路”，开表示使用效果、关表示跳过效果；与麦克风静音分开 |
| EQ | 保留一个 EQ 总开关；选择“默认 / 已保存主题 / 自定义”，不再逐段勾选才能调节 |
| 当前预设 | 显示“无 / 预设名称 / 自定义”；修改已加载主题后显示“自定义” |
| 普通调音 | 保留直观的音色和强度操作，改变后实时生效 |
| 高级功能 | 集中提供逐段频率、增益、Q、高低通、压缩、降噪和变声等详细参数，默认收起 |
| 创意声音 | 选择一个主题并启用即可，不要求组合内部效果开关 |
| 收藏 | 使用清楚的筛选按钮或标签，优化当前“只看收藏”复选框 |
| 静音 | 使用明确的麦克风/静音按钮，显示真实状态 |
| 语言 | 简体中文 / English，覆盖页面、按钮、状态、错误与提示，并记住选择 |

普通模式不堆放参数、术语和重复说明。高级模式与普通模式编辑同一份设置，切换模式不能丢失参数或突然改变声音。

### 关键语义

- **实时生效、自动保存、另存主题是三个动作。** 保存文件不能代替更新正在运行的音频处理器。
- 新工作区的默认 EQ 可直接使用；已保存的用户选择优先恢复。旧主题迁移不应无提示地打开原本关闭的高增益频段。
- “无”仅表示没有选用预设，不等于静音、停止或关闭全部效果。
- “恢复默认”只重置当前调音参数，不删除个人主题、设备选择或语言等偏好。
- 原代码使用“旁路=true”表示跳过效果；改名时必须正确转换为“效果开启=false”，不能只换文字。
- 软件停止处理不等于关闭其他应用正在使用的系统麦克风。自研 APO 路线需明确停止时的透传行为；虚拟线路停止会停止本软件发送。

## 3. 记忆、托盘与开机启动

记忆范围：输入设备、效果与 EQ 状态、主题选择、自定义参数、增益、语言和启动偏好。设备按稳定 ID 恢复，断开时保留选择，不自动换成其他麦克风。

- 点击窗口关闭按钮：默认收进托盘，继续当前处理和虚拟输入发送。
- 托盘：打开窗口、暂停/继续处理、明确的“退出软件”。窗口和托盘共用同一份处理状态。
- 真正退出：停止本地音频并释放资源；自研 APO 的退出行为须同步设计，避免界面退出后出现未说明的持续增强。
- 开机启动：用户可开关，开启后随当前用户登录 Windows 启动，支持直接进入托盘；卸载清理自建启动项。
- 参数损坏时保留副本并提示恢复，不直接覆盖个人主题。

**已确定的启动策略（0.3.0 实施）：**“记住参数”“登录后启动软件”“自动开始处理麦克风”分别管理。默认恢复参数并进入托盘；登录启动默认进入托盘且不弹出主窗口；自动开始处理由独立选项控制，默认关闭。手动启动永远不会自动打开麦克风。

## 4. 声音能力

### 4.1 语音优先与自动清理

目标是自动识别人声、估计并跟踪底噪，尽量不要求用户手动学习噪声。普通界面只提供模式或简单强度。

| 能力 | 要求与验证重点 |
| --- | --- |
| 人声检测 | 正常讲话、轻声、辅音和句尾不能被错误截断 |
| 自动降噪 | 持续风扇/空调声与键盘等突发噪声分别测试，不承诺全部消除 |
| 声学回声消除 AEC | 使用实际播放参考信号，验证对方说话、自己说话和双方同时说话 |
| 房间混响抑制 | 与扬声器回声分别评估，不把普通门限当作回声消除 |
| 动态与输出保护 | 音量稳定、避免明显抽吸或突响；不能修复麦克风硬件已经削波的声音 |

算法或模型在正式开发时核对来源、版本、许可、CPU、内存、算法延迟和离线运行能力。缺少必要播放参考时明确 AEC 能力限制，不能显示虚假的“已消除”。

建议先清理输入语音，再做 EQ、动态和创意变声，最后控制输出峰值。创意主题主动加入的回声/混响不应被前级自动清理互相抵消；最终顺序由实录验证。

### 4.2 创意变声主题

| 批次 | 主题 | 实现要求 |
| --- | --- | --- |
| 第一批 | 爆炸麦、机器人、电话/电台、回声空间 | 基于确实可用的失真、调制、滤波和空间效果组合，默认输出音量受控 |
| 第二批 | 氢气音、萝莉音 | 使用可信的实时音高/共振峰处理；不能用单纯加速播放或环形调制冒充 |
| 后续扩展 | 怪兽/低沉、外星人及其他恶搞主题 | 按真实实现质量与试听结果逐项开放 |

主题提供少量简单操作，详细参数留在高级功能。支持记忆、自定义、另存和运行中切换；切换不能造成长时间静音、爆音或不可控增益。

## 5. 自研 APO 技术路线

### 最终目标

移除面向第三方 Equalizer APO 的配置、安装引导和依赖，改为 Mic Studio 自有 APO 组件，由软件统一管理安装、目标设备绑定、更新和恢复。

```text
Mic Studio 界面
   ├─ 设置、主题与实时参数控制
   ├─ 自有组件安装及诊断
   └─ Mic Studio APO → Windows 麦克风音频链路 → 接收应用
```

现有本地 DSP 与虚拟线路可作为开发期间的可运行基线。**自研 APO 通过验证前不先删除可用处理路线**；目标完成后再移除第三方接入。是否进一步替换 VB-CABLE 属于独立的虚拟输入方案，不因自研 APO 就默认拥有自有虚拟麦克风驱动。

### 技术拆分

1. **可行性验证：**原生 APO 最小工程、指定测试录音端点绑定、透传和可测的固定衰减，证明 Windows 实际加载并处理音频。
2. **处理核心：**评估原生 C++ 实时处理层与现有算法的复用；不直接把整个 .NET 图形程序放进系统音频处理回调。
3. **参数通道：**界面在非实时线程中校验、保存设置，音频线程读取一致的参数快照；避免回调中等待文件、锁或网络。
4. **安装与分发：**组件注册、设备关联、必要签名与发布条件、按需 UAC、版本检查、卸载与回滚；不自动重启系统。
5. **故障处理：**安装取消、错误参数、进程异常、设备重建和更新失败时可恢复，避免影响非目标设备。
6. **真实验证：**区分组件存在、设备已绑定、Windows 当前路径生效及接收应用生效，诊断只展示当前路线相关信息。

自研 APO 的系统组件、签名、安装和兼容性是独立工作包。当前 0.5.0 已有真正的 C++ COM DLL、增益/八段 EQ/限幅、离线宿主及托管参数桥接，未将本地 C# DSP 或第三方适配器改名冒充自研 APO。参数 ABI 为 little-endian、Pack=4、224 字节 v2，通过端点文件映射及奇偶 seqlock 提交；控制器每秒续期，来自未来时间戳或超过 3000 ms 的心跳导致透传。正常控制使用协商流格式，停止/退出写入停用状态，失去控制器时靠租约回退。

安装预览检查原生导出、Windows 签名信任、ABI/CLSID、文件散列与目标端点审批指纹，已有外部效果不自动替换；用户确认后才允许独立 helper 请求管理员操作，并留下受保护的备份/结果记录。当前无证书的开发构建被禁止系统注册和绑定，不降低受保护音频策略。Windows 加载、签名部署和实际声音验证未通过前，不标为“自研 APO 已完成”；缺少这些部署条件不再阻止工程实现、构建和离线测试。

官方技术依据：[APO 架构](https://learn.microsoft.com/en-us/windows-hardware/drivers/audio/audio-processing-object-architecture)、[实现 APO](https://learn.microsoft.com/en-us/windows-hardware/drivers/audio/implementing-audio-processing-objects)。

## 7. 验收清单

### 简易操作

- 无需逐段启用 EQ；默认、个人主题、自定义可以直接选择。
- 处理中改变增益、EQ 和主题，声音同步变化，不再出现“已保存但未应用”的操作陷阱。
- 普通界面没有应用、撤销、重做或采集运行计时；恢复默认不删除个人内容。
- 效果开关、EQ 开关、麦克风静音、开始/停止和预设名称各自含义明确。
- 中文、英文长标签、键盘操作以及 100%～200% DPI 下关键控件可见可达。

### 后台与恢复

- 关闭窗口收进托盘，音频不中断；明确退出后停止本软件处理并释放资源。
- 重启恢复参数，主题与设备对应正确；断线不误选其他麦克风。
- 登录启动项可以启用和关闭，卸载清理自建启动项；自动采集行为与用户选择一致。

### 音频与组件

- 合成信号验证 EQ、增益、动态、变声和参数切换；真实语音另测正常说话、轻声、尾音、键盘、停顿和突然较响。
- 降噪、AEC 和房间混响分别验证；不把一个功能的效果宣传为另一个功能。
- 自研 APO 必须在真实 Windows 路径上测到预期变化，且只影响指定设备；接收应用另行确认。
- 进行至少一小时连续处理、拔插、睡眠唤醒及采样率变化测试；端到端延迟采用实际测量，不能用缓冲长度代替。
- 验证安装/升级/卸载、UAC 取消、组件异常和回滚；保留个人设置、主题、额外录音与已修改文件。

## 8. 本轮交付与后续启动方式
