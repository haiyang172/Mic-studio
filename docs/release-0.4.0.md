# Mic Studio 0.4.0 预览版 · 语音优先、音高主题与 Q 版角色

> 0.4.1 已按用户反馈恢复简洁 MS 字母图标；Q 版角色不再用于发行。见 [0.4.1 更新说明](release-0.4.1.md)。

本版在 0.3.0 的后台/双语基础上，交付可运行的 P3 语音与创意主题预览，并完成 P5 的 Q 版 MS 角色图标。P4 自有 Windows APO 仅提交设计与阻塞说明，未完成。

## 语音优先降噪

- 降噪新增“自动跟踪底噪”：低能量帧更新噪声估计，讲话帧只允许极慢上升，并受最大衰减限制。
- 新增“语音优先”：强讲话时减少各频段过度衰减，优先保留轻声、辅音和句尾；普通强度仍为 0～100%。
- 关闭或旁路时不引入额外处理；启动、停止和参数快照沿用 0.3.0 的实时更新路径。

## 创意主题与实时变调

- 新增 **爆炸麦、电话/电台、氢气音、萝莉音、怪兽/低沉**，保留温暖、机器人、回声、空间和自定义。
- 音高范围 −12～+12 半音，使用双读头延迟线变调和交叉淡化；不是加速播放或环形调制。
- 电话/电台上限带限和软饱和；主题强度、音高、电话开关进入高级功能。
- 创意总开关关闭再开启会恢复自定义组合和参数。

**边界：** 氢气音/萝莉音是**音高预览，不保留共振峰**；本版没有 AEC、房间混响抑制，也没有自然共振峰变声。真实语音的轻声、辅音、尾音、双讲和键盘噪声仍需人工试听。

## Q 版角色图标

- 新图标为薄荷色 Q 版角色，佩戴耳机和麦克风，胸前 MS 徽章，保留石墨色圆角底板。
- 16/20/24 像素自动使用紧凑 MS 字母标；32 像素起保留角色轮廓，隐藏腮红、高光和徽章等细节。
- 重新生成 SVG、512 px PNG 和九层 Windows ICO，用于窗口、任务栏、托盘、EXE 和安装器。

## P4 自有 APO

本机缺少 Windows Kits/WDK、`cl.exe`、`signtool.exe`、管理员注册环境和签名证书，无法真实加载/绑定/验证自有 APO。本轮只提交 [设计与阻塞说明](architecture/apo-own.md)，不把现有本地 DSP 或第三方 Equalizer APO 改名冒充。第三方 APO 路线继续保留为可用基线。
