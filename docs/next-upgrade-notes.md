## 最新补充：EQ 的简易入口

- 普通界面可保留一个明确的 **EQ 总开关**；需要减少的是逐频段“启用此频段”等繁琐开关，不是一律取消所有开关。
- 开启 EQ 后，可直接选择：**默认 / 已保存主题 / 自定义**。
- 默认：使用合理的基础配置，不要求逐段启用。
- 已保存主题：直接选择个人保存的 EQ 配置。
- 自定义：允许自行调节并另存为主题，频率、Q 等细节放到高级功能。
- 保留实时调节目标。此交互方案仅作后续设计记录，尚未实施。

## 主要交互要求

- 首要重点：去掉当前“先勾选启用，再调参数”的繁琐开关操作。均衡器不需要逐段打开开关。
- EQ 默认全部生效，直接调节，实时听到变化；不再每次点击“应用”。
- 普通界面面向简单操作，频率、Q 等均衡器细节统一放进高级功能。
- 常用声音效果同样简化，技术参数和详细调节只在高级功能中显示。
- 创意声音提供少量明确主题；用户选择并启用主题即可，不需要逐项组合饱和、混响、回声、机器人等内部开关。
- 保持已有的简洁、高对比界面，避免重复说明和无信息文字。
- 更容易上手和完成操作：减少步骤、开关和专业术语；常用操作尽量一两步完成，默认参数合理、入口明确，遇到问题给出清楚的下一步操作。普通用户无需理解频段、Q、压缩门限等概念，也能完成基本调音。

## 记忆与后台运行

- 记住上一次使用的设备、EQ 总开关、默认/主题/自定义选择、音量增益和效果设置，下次打开时恢复。
- 区分“恢复参数”和“重新启动后自动采集麦克风”；后者的具体启动行为留待实施时明确，不因记住参数就隐式改变。
- 点击窗口关闭按钮，默认收进系统托盘，软件继续在后台运行，正在进行的音频处理和虚拟输入发送保持运行。
- 关闭窗口不等于退出软件，也不应中断正在使用的输入。
- 托盘提供打开主窗口、暂停/继续处理和明确的“退出软件”入口；真正退出时停止并释放本地音频资源。
- 本轮仅记录上述偏好，不修改现有关闭行为或启动设置。

## 开始/停止与实时调音（用户截图补充）

- 取消主界面及底部状态栏的“正在采集……02:05”采集运行计时，避免呈现成录音计时器。采样率、声道等技术信息可留在高级设置或诊断。
- 主页面采用播放器式的开始/停止交互，明确区分未运行与处理中；主操作随当前状态呈现“开始处理”或“停止”，避免两项状态含糊。
- **主要要求：处理运行时，修改 EQ 或输入增益立即作用于当前声音，不需要再点击“应用”，也不需要停止、重新开始。**
- 点击开始时直接使用当前选择的默认配置、保存主题或自定义参数；停止后保留参数，供下次开始使用。
- 实时参数更新应平滑，避免突变声；不要将“自动保存参数”误当作“已经实时改变声音”。
- 上述采集计时取消不等于取消用户主动录音的状态提示；录音交互后续单独设计。
- 本轮仅记录，不修改现有处理按钮、计时显示或音频应用行为。

## 顶部操作栏精简（最新截图）

- 移除截图中的“应用”“撤销”“重做”三个按钮，普通界面只保留一个 **“恢复默认”** 按钮。
- 参数变化实时生效，不再依赖“应用”按钮。
- 恢复默认只重置当前调音参数，不删除个人保存的主题、预设或设备设置。
- 本轮仅记录，不修改现有按钮。

## 命名、语言与当前预设

- 将“旁路”改为 **“效果开关”**，使用直观的开启/关闭语义：开启表示使用本软件效果，关闭表示跳过本软件效果，不是麦克风静音。实施时需同步转换原旁路布尔语义，避免显示与声音相反。
- 增加 **英文界面**，支持简体中文/English 切换并记住选择；覆盖页面、按钮、状态和提示，不仅翻译导航名称。
- 当前预设显示为 **“无” / 实际预设名称 / “自定义”**，不再使用含糊的“平直·未保存”状态组合。
- “无”表示没有选用预设；载入保存的预设时显示其名称；手动修改成不再匹配该预设时显示“自定义”。
- 此项属于当前预设的显示方式，不等于关闭效果；保存主题和参数记忆仍按前述要求设计。
- 本轮仅记录，不修改现有语言、状态名称或预设逻辑。

- 图标仍须简洁，在窗口、任务栏及托盘的小尺寸下保持辨识度。

## 创意变声预设

- 增加可直接选择并启用的变声主题：**爆炸麦、机器人、氢气音、萝莉音**，以及其他恶搞音效。
- 可继续扩展电话/电台、怪兽/低沉、外星人、回声空间等主题；具体效果以真实实现及试听结果为准。
- 普通模式选择主题即可使用，可提供简单强度调节；音高、共振峰、失真、调制等细节放入高级功能。
- 氢气音和萝莉音按音效名称设计，评估实际音高与共振峰处理；不把环形调制或单纯加速播放冒充自然变调，不涉及吸入气体。
- 爆炸麦通过失真/饱和等音色处理模拟，保持最终输出限幅和可控音量，不靠危险的超大增益制造效果。
- 支持记住上次主题、自定义及另存，运行中切换应及时生效并避免突变声。
- 本轮仅记录，不实现、不生成音频，也不改变现有处理。

## 语音优先与自动清理

- 增加“语音优先”模式，自动识别人声活动并区分背景噪声，优先保留正常说话、轻声、辅音和句尾。
- 自动估计与跟踪底噪，抑制风扇、空调等持续噪声，并评估键盘等突发噪声的处理；普通模式尽量不要求手动学习底噪。
- 增加自动回声处理：区分扬声器播放反馈的声学回声消除（AEC）和房间混响抑制，按实际支持的能力实现及命名。
- AEC 需使用实际播放参考信号；不能以噪声门或创意回声效果代替。无可用参考时明确能力限制。
- 普通界面提供简易模式或强度选择；具体算法、阈值和参考设备等放入高级功能，记住用户设置。
- 以语音完整性和自然度优先，避免吞字、截断尾音、明显水声及多重降噪叠加。自动识别和抑制以实录验证，不承诺彻底去除所有噪声或回音。
- 与创意变声中的回声/混响主题明确区分，避免自动清理与用户主动选择的创意效果互相抵消。
- 本轮仅记录，不接入模型、不打开麦克风、不修改现有算法。

## 开机启动

- 增加可由用户开启或关闭的“开机启动”选项，并记住选择。
- 开启后，在当前用户登录 Windows 时启动 Mic Studio；可配合托盘后台运行，避免每次弹出主窗口。
- 启动后恢复上次参数；是否立即恢复麦克风处理单独明确，不把开机启动与自动采集混为一项。
- 卸载时清理本软件创建的启动项。
- 本轮只记录，不创建实际开机启动项。

## 用户截图补充：需要优化的具体控件

以下四处均列入未来 UI 优化范围，本轮只记录：

- **只看收藏**：优化预设筛选的呈现，可考虑筛选按钮或标签，避免生硬的默认方框。
- **启用压缩**：优化效果状态与操作入口，配合简单强度调节；技术参数留在高级功能。
- **启用此频段**：优先去掉逐频段启用的前置操作，EQ 默认生效、直接调节。
- **麦克风静音**：改成清楚的麦克风/静音按钮，明确区分静音和正常输入状态，避免复选框语义不直观。

统一检查这些控件的字体、对比度、图标、间距、点击区域、键盘焦点及不同 DPI 下的显示。按筛选、效果状态和静音各自的用途设计，不机械地全部换成同一种开关；静音等真实功能仍须保留。

## 未来技术方案：自研 APO（最新决定，仅记录）

用户明确希望：**移除第三方 Equalizer APO 接入，开发并使用 Mic Studio 自己的 APO，集成在软件中管理。** 此决定替代此前仅将自研 APO 作为可选评估的方案；当前仍处于记录阶段。

- 不再要求用户另装或配置 Equalizer APO，移除面向该第三方软件的接入入口。
- 自研组件需真正接入 Windows APO 音频链路；现有本地 DSP 可作为算法复用来源，但不能直接改名冒充系统 APO。
- 软件统一管理自有组件的安装、设备绑定、状态检测、更新及恢复；具体实现需包含实时处理、注册、签名分发与兼容性验证。
- 诊断页改为显示当前实际路线及自有组件状态，不再在本地 DSP 模式下突出“第三方 APO 未检测到 / 待验证”等无关提示。未安装、已绑定和音频实际生效仍分别表示。
- 自有虚拟输入与现有 VB-CABLE 的后续关系另行设计，不因这条要求立即卸载或修改现有驱动。
- 本轮不开发自研 APO，不移除现有代码，不安装或修改系统组件。
