# Mic Studio 0.8.0 开发预览 · 去齿音与循环调音

- 效果页加入去齿音。强度设为 0% 时关闭，门限与中心频率在高级功能中。适用于本地 DSP 与 CABLE 线路。
- 在麦克风页展开高级功能，录制一段 A/B 源。停止采集并在设备页确认耳机后，点「循环调音」。播放条会留在各页面，可在原声 A 与效果 B 间切换，同时调整均衡器、增益和效果。普通试听默认配平音量，关闭配平可听出增益带来的音量差。
- 调音引导用约 6 秒的正常讲话电平计算增益建议。已有 A/B 源时可用耳机试听建议，点击「采用建议」后保存。建议试听默认保留增益差。
- 循环试听使用已保存的源录音和确认过的耳机输出。开始实时处理、更换输出、取消耳机确认、锁屏或休眠会结束试听。

人声听感、不同耳机的播放延迟和外部通话接收仍待实机验收。

下载 `MicStudio.Setup.exe` 或 `MicStudio-win-x64.zip`。
