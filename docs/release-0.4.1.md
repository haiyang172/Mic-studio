# Mic Studio 0.4.1 预览版 · 恢复简洁 MS 图标

按用户反馈，0.4.0 的 Q 版角色图标不再使用，恢复原来的 **MS 字母标**：

- M 为 Mic、S 为 Studio；薄荷绿连笔和短支架呼应麦克风。
- 保留石墨色圆角底板；16/20/24/32/40/48/64/128/256 九层 ICO 重新生成。
- 32 像素以下隐藏细小支架，优先保留字母识别度。
- 侧栏、窗口、任务栏、EXE、托盘和安装器使用同一套新生成的 PNG/ICO。

本版**不改变**音频处理、设置、托盘、登录启动或语言行为；P3 的 AEC/混响/共振峰限制和 P4 自有 APO 阻塞状态与 0.4.0 相同。

## 验证

- 构建 0 警告、0 错误。
- Core 40、APO 20、WindowsAudio 39、Components 24、Setup 40 全部通过。
- WPF 47 项控件/事件检查、27 种中文布局、27 种英文布局，英文未翻译汉字 0。
- 512 与 16 像素图标目视检查。

详细记录：[P3/P5 验证](validation/p3-p5.md)。真实语音、安装/升级/卸载和 DPI 仍需人工验收。
