# P7 备用麦克风与排除名单验证

2026-11-09，Mic Studio 0.7.1 开发预览，Windows x64。本记录覆盖本地构建、合成音频、模拟端点和隔离界面验证。

## 本地验证结果

- Release 构建通过，零警告、零错误。
- Core 40 项、APO 20 项、WindowsAudio 124 项、Shortcuts 14 项、Components 24 项、NativeApo 26 项和 Setup 40 项检查通过。
- WPF 隔离界面通过 141 项操作检查，以及 39 种中文和 39 种英文窗口布局检查。横向溢出、滚动不可达和英文界面漏译汉字均为零。
- 托管与原生回声处理的合成互操作检查通过。

检查使用合成端点、时钟和启动适配器，音频样本在内存中处理。验证期间没有启动实体麦克风采集、耳机播放或 CABLE 发送。

## 授权与恢复行为

- 新建工作区的断线恢复和备用切换均默认关闭。仅保存开关、备用顺序、格式快照和排除项，已有断线恢复偏好按原值读取。每次运行由已经开始的本地/CABLE 线路建立恢复授权。
- 最多 8 个明确选择的备用按顺序验证，最多 64 个排除项作用于自动首次选择、恢复和备用。手动选择与开始仍可使用排除项，已排除的当前输入不建立自动恢复授权。
- 候选端点身份、保存的采样率/声道及共享 CABLE、耳机监听必须符合本次授权。备用进入稳定等待后持续核对至少 1 秒，候选变化重新计时。有效的待恢复备用可继续完成等待，原设备返回时保持当前输入，可手动切回。
- 停止、设备或监听变化、锁屏或休眠、文件回放和啸叫保护会撤销授权。恢复失败后暂停，任意 60 秒内最多 3 次自动尝试的限制覆盖多次备用切换。
- 切换成功后更新并记住当前输入、提示用户并解除原设备音量锁定。复核覆盖提交期间取消、新旧会话代次、迟到的保护事件和新旧控件事件，已撤销的操作不能重新授权或覆盖后续手动选择。

新版控件回归包含备用添加、排序、移除、格式更新、排除管理、设置记忆、默认折叠和展开后的布局。既有停止、按住说话、线路状态和诊断脱敏继续接受检查。

真实麦克风及备用设备拔插、CABLE 端点重建、Discord 收音、锁屏与休眠唤醒，以及长期后台运行仍待实机验收。P7 软件功能开发预览已覆盖计划范围，完整 P7 验收及 P3/P4/P5 的既有未完成项继续保留。
