# P7 声音线路与同设备恢复验证

0.7.0 开发预览在 Windows x64 上通过 Release 构建。Core 40 项、APO 20 项、WindowsAudio 107 项、Shortcuts 14 项、Components 24 项、NativeApo 26 项和 Setup 40 项合成检查通过。隔离界面通过 116 项操作检查，以及中英文各 39 种布局检查。

恢复验证使用模拟端点、时钟和启动结果。检查覆盖原设备与采样格式、稳定等待、滚动限次、普通故障、主动取消，以及锁屏或啸叫保护与恢复同时发生的情况。线路检查覆盖未采集、线路不完整、接收待确认和诊断脱敏。

真实设备验收仍包括拔插原麦克风、重建 CABLE 端点、锁屏与唤醒、Discord 收音及长时间运行。备用设备和排除名单属于 P7 后续。
