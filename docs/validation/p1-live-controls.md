# P1 实时简易版验证记录

日期：2026-10-29（Australia/Sydney）。版本：0.2.0 预览版。Windows 11 x64，.NET SDK 10.0.403。

## 本轮范围

- 主页面单个开始/停止按钮；去掉底部采集时长及采样率/声道堆叠。
- 移除普通页面的应用、撤销、重做；只保留恢复默认，不删除个人主题、设备及偏好。
- 效果开关正确映射 `Bypass` 的反向含义；与系统麦克风静音独立。
- EQ 一个总开关、六个直接调节的音色控制、默认/主题/自定义；频率、Q、高低通和曲线拖动放在高级功能。
- 常用效果简化，强度用百分比显示；创意声音的主题组合来自现有算法，自定义组合关闭再开启仍保留。
- 运行中的本地 DSP / CABLE 实时接收最新参数；停止时编辑、选择主题和恢复默认只保存设置，不打开音频。

P2 的默认托盘、开机启动与英文，P3 的新降噪/AEC/音高算法，P4 自研 APO 和 P5 角色图标不属于此版本。

## 音频更新与旧数据

UI 最多约每 30 ms 合并提交最新参数，不启动竞争的后台任务；提交带有采集会话编号，停止、设备切换或重启后拒绝旧会话更新。参数校验和滤波器准备在采集锁外完成，音频包边界接收一致快照。增益使用约 5 ms 平滑，EQ 使用约 10 ms 过渡。降噪、回声及混响的大型历史缓冲只在处理器创建时分配，不随滑条重复创建。

新的默认 EQ 八段启用：20 Hz 高通、20 kHz 低通及零增益的其他频段。平直内置主题仍是关闭 EQ 的平直处理。旧 JSON 缺少总开关时沿用启用值，但每段原有 `Enabled` 和增益完整保留，不会自动开启旧主题中关闭的高增益频段。处理副本按实际采样率适配，原始主题参数保留；开始时如有适配会明确提示。低采样率曲线使用相同处理副本。

第三方系统 APO 路线仍在设备页手动预览/更新，普通参数修改不静默写受保护配置、不弹出连续提权请求，不显示为本地实时更新成功。EQ 总开关同时用于生成系统 APO 配置。

## 自动验证

- Core：36 项，包括实测 EQ 总开关、平滑更新、延时历史、参数快照、旧数据、低采样率和频繁更新分配上限。
- APO：20 项，包括总开关关闭时保留数字增益但不输出滤波器，以及原有配置保护。
- WindowsAudio：28 项合成/空闲检查，涵盖停止/旧会话拒绝、8/16 kHz 默认 EQ 离线处理及原有设备/格式/文件保护。
- Components：24 项。原生安装器：40 项模拟检查；未实际安装或卸载。
- WPF：29 项实际控件路由事件，验证直接调增益、主开关语义、主题与开关同步、EQ 主题保留其他参数、自定义创意组合保持、恢复默认保留个人内容、显示取整不会意外修改参数，以及停止时所有操作不打开音频。
- 布局：1280×820、900×600、600×500 三个窗口尺寸，共 27 种页面/高级展开布局，检查横向溢出和滚动可达；另检查浅色页面。截图仅在本机隔离的 `artifacts/p1-ui` 中生成，不上传用户设备信息。

复验：`scripts/Build.ps1`、`scripts/Test.ps1`、`scripts/Test-UI.ps1`。界面检查总是使用新的隔离工作区，不覆盖个人设置；不会改变 Windows DPI。

## 实际虚拟线路验证

在匹配的 CABLE Input/Output 上发送 997 Hz、−36 dBFS 合成信号，仅打开虚拟端点，不打开实体麦克风、扬声器、监听或录音。`--live-update-smoke` 实测结果：

| 阶段 | 输出与输入 RMS 差值 |
| --- | --- |
| 初始平直 | 0.000 dB |
| 输入增益 −6 dB | −6.000 dB |
| 同时加入 +6 dB EQ | 0.000 dB |
| 关闭 EQ 总开关 | −6.000 dB |
| 连续 60 次修改，最终 −3 dB | −3.000 dB |

所有阶段保持同一采集会话编号，不停止重启；旧会话和停止后的更新被拒绝。该测试是实际 WASAPI 虚拟线路处理验证，界面事件检查单独进行。

复验：`.tools/dotnet/dotnet.exe run --project tests/MicStudio.WindowsAudio.Tests -c Release -- --live-update-smoke`。没有匹配虚拟端点时拒绝运行，不自动换用其他设备。
