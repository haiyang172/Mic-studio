# Mic Studio 0.1.0 — 本机验证记录

日期：2026-10-28（Australia/Sydney）。本记录区分源码测试、真实虚拟线路与尚未执行的实际语音验收。

## 已完成

- Windows 11 x64，.NET SDK 10.0.403；锁定 NuGet 依赖，普通构建与 win-x64 自包含发布可连续使用 locked restore。原生 WPF 构建零警告、零错误。
- Core 28、APO 配置 19、WindowsAudio 25、Components 24 项检查通过，共 96 项。安装器 40 项独立检查通过，涵盖路径、解包、归属清单及用户录音/已修改文件保留；未执行真实系统安装或卸载。
- 发行版 WPF 的 12 项真实控件事件检查通过：数字输入、非法值、撤销/重做、EQ 开关、预设、缺线路拒绝、停止时应用不打开麦克风、校准取消及诊断数据隔离。
- 7 个页面在 1280×820、900×600、600×500 DIP 共 21 个实际窗口布局检查通过，无水平溢出；需要滚动的页面可到达末尾。浅色代表页面已渲染检查。未改变系统 DPI，没有将该检查说成全 DPI/跨显示器验收。
- 便携发行 EXE 实际启动并完成上述窗口检查，加载的是随包的 hostfxr/coreclr/WPF DLL；未依赖 SDK。发行版包含 .NET 10.0.14 运行时。
- 普通权限真实枚举到 USB PnP 麦克风（48 kHz 双声道）及 CABLE 两个端点。系统输入音量只读查询成功，没有在开发测试中改动系统音量或静音。
- 虚拟线路使用生成的 997 Hz / −36 dBFS 信号验证传输。真实 AudioEngine 的 −6 dB 设置测得 −6.000 dB；并发停止和快速启停通过。仅使用虚拟端点，没有通过扬声器播放或打开物理麦克风。
- 驱动官网检查、强制重新下载和实际签名检查通过。Pack45 原包 SHA256 与固定发布清单一致，官方安装器 Windows 信任验证通过；没有运行驱动安装或请求 UAC。
- 原生安装器自检及内嵌 payload 检查通过；发行目录包含官方 VB-CABLE 原包、完整原始文件、运行时及第三方告知。没有打包 SDK、个人设置、录音、日志或凭据。
- 主程序默认不开采集、录音或监听；录音由用户选择保存位置。UI 测试模式始终创建独立工作区，不覆盖日常设置。

## 尚需实际验收

物理麦克风讲话与主观音质、校准对真实讲话的适合程度、APO 目标端点绑定与实际生效、任意接收软件的实际音频结果、耳机监听、安装/升级/卸载与 UAC 取消、拔插、睡眠唤醒、跨显示器 DPI、一小时真实连续处理与端到端延迟均未由上述检查替代。

降噪是固定底噪参考的经典频谱算法，不是 RNNoise。离线 A/B 使用同源录音整段 RMS 匹配，不是 LUFS；最终限幅基于采样峰值，不是真峰值。

常规 UI 的诊断导出已脱敏。供开发使用的 `--diagnostics` 输出包含设备名称，异常时可包含本地路径，因此不得当作完全脱敏的公开报告。原始窗口截图与完整诊断留在被忽略的本地测试目录。
