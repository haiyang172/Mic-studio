# P3 语音/变声预览与 P5 角色图标 · 0.4.0 验证记录

验证日期：2026-10-29。环境：Windows 10.0.26200，普通权限，.NET SDK 10.0.403。未打开实体麦克风、监听或录音；未安装驱动或修改系统音频配置。

## 实际交付

### P3 语音与创意主题（预览）

- 降噪增加“自动跟踪底噪”：用低能量帧缓慢更新噪声估计，语音帧只允许极慢上升，并以最大衰减限制防止过度吞声。
- 降噪增加“语音优先”：按宽带信噪比估计讲话存在概率，强讲话时把每频段目标增益向 1 dB 拉回，优先保留轻声、辅音和句尾。
- 新增实时音高移调（−12～+12 半音），采用双读头延迟线变调与三角交叉淡化；关闭时为严格旁路，不引入算法延迟。
- 新增创意主题：爆炸麦、电话/电台、氢气音、萝莉音、怪兽/低沉；保留温暖、机器人、回声、空间和自定义。
- 音高/电话状态纳入创意总开关和自定义组合记忆；关闭再开启会恢复组合，不丢已有参数。

**明确未交付：**

- **没有实现 AEC。** 没有播放参考信号采集、双讲检测和自适应回声消除；不能用噪声门或创意回声冒充。
- **没有实现房间混响抑制。**
- 音高为延迟线变调，**不保留共振峰**；氢气音/萝莉音不是自然音高或共振峰处理，UI 与 README 均按预览描述。
- 未做真实语音试听、双讲、轻声/尾音和键盘噪声验收；自动测试只证明算法路径和合成信号行为。
