## 独立图标与 Logo 方向

1. 声脉：用流畅的声音脉冲形成独立图形，保留音频联想。
2. 声环：用饱满的环形与留白表现共振，强调简洁和辨识度。
3. 负形麦克风：用几何轮廓中的留白构成麦克风，直观但避免通用剪贴画。
4. 抽象声翼：用流动折带表现声音传播，更轻盈、有动感。

每个方向先展示应用图标、独立符号与 Mic Studio 字标组合。初稿为图像生成的审美探索预览，不代表可直接发布的矢量图标；选定后重新整理矢量轮廓，并实际检查 16/32 像素及单色托盘。前两轮仅提供预览；本轮进入所选 A2 的正式资产制作与应用。

首轮四套预览已生成，保存在本机 `artifacts/p5-logo-proposals-2026-10-29/`，完整提示词见同目录 `prompts.md`。四套均未使用 MS 字母构成图形。用户先选择 A 声脉方向细化，现已明确选定 **A2 翡翠流线**。

第二轮沿用 A 的圆润声脉，提供四个相近变体：A1 清亮薄荷（最接近原稿）、A2 翡翠流线（稍纤细）、A3 冰薄荷（紧凑饱满）、A4 浅玉（浅薄荷底、深青绿色图形）。预览与完整提示词保存在 `artifacts/p5-logo-A-variants-2026-10-29/`。该轮没有替换软件图标。

用户最终选择 A2：深蓝绿色底板、翡翠青绿色的连续圆润声脉，较纤细流畅、轻微不对称，配 Mic Studio 字标；不使用 MS 字母图形。

## 已选定：简洁主页、主题卡片与高级功能

用户于 2026-11-05 确认以下方向，0.6.1 整理现有界面：

- 主页参考 Krisp/NVIDIA Broadcast 的简洁设备与效果操作，集中系统音量、增益、真实电平及一个开始/停止按钮；发送静音保持直接可用。
- 创意声音与声音预设参考 Voicemod 的主题选择方式，点击卡片选择，明确标记当前状态；个人预设的复制、收藏、重命名、删除及导出收进管理区。
- Windows 麦克风静音、增益校准、录音与 A/B 收进主页高级功能；具体 EQ/效果参数继续默认折叠。处理方式移至“设备 → 高级连接”。
- 保留 A2 品牌、深浅主题、中英文、参数记忆、后台控制与现有音频算法。界面选择与展开操作不自动启动音频。
- Soundpad 的音效列表/播放器作为 P9 的交互参考，本版不新增音效板；多路混音仍是后续高级功能。

整套 Windows DPI/高对比、跨屏、真实键鼠与音频、安装升级卸载继续按升级计划验收。本次选定及实施界面方向，不标记完整 P5 或 P4 系统音频验收通过。
