## 独立图标与 Logo 方向

1. 声脉：用流畅的声音脉冲形成独立图形，保留音频联想。
2. 声环：用饱满的环形与留白表现共振，强调简洁和辨识度。
3. 负形麦克风：用几何轮廓中的留白构成麦克风，直观但避免通用剪贴画。
4. 抽象声翼：用流动折带表现声音传播，更轻盈、有动感。

每个方向先展示应用图标、独立符号与 Mic Studio 字标组合。初稿为图像生成的审美探索预览，不代表可直接发布的矢量图标；选定后重新整理矢量轮廓，并实际检查 16/32 像素及单色托盘。暂不替换现有品牌资产、不构建或发布软件。
