# Mic Studio 0.1 设计与实施依据

原生 WPF 工作台，保留简洁界面：删除标语、装饰英文和重复说明，使用较高对比度的深/浅主题。左侧七个页面为麦克风、均衡器、效果、预设、设备、诊断、设置；窄窗收起导航文字，内容可滚动，卡片自动换行。

```text
┌ Mic Studio ───────── 输入设备 / 处理方式 / 旁路 ──────────┐
│ 麦克风      应用 / 撤销 / 重做                           │
│ 均衡器      [系统音量 / 静音]     [采集输入电平]          │
│ 效果        [数字增益]            [处理后电平]            │
│ 预设        [开始 / 停止]                                │
│ 设备        [平直 / 自然 / 清晰 / 温暖 / 另存]            │
│ 诊断设置    [校准、录音与比较：默认折叠]                  │
└ 未运行 / 待应用 ─────────────────────────────────────────┘
```

面向任意可选择音频输入的录音、会议、直播、通话软件。系统音量和静音立即改变所选 Windows 麦克风端点；本地处理后声音通过 CABLE Output 供其他软件选择。Discord 只作为可选应用示例，不是主流程。

APO 直接路线仅导出增益与八段 EQ，动态及降噪在本地处理路线开放。APO 缺失仍可使用虚拟输入；新工作区在缺少 APO 时默认选择本地处理。切换设备或路线停止采集，不把本地测量标为系统 APO 已生效。

信号顺序：输入数字增益 → 固定底噪频谱衰减（可选） → 八段 EQ → 压缩 → 轻柔扩展/噪声门（可选） → 创意处理（可选） → 输出补偿 → 采样峰值限幅。本地 DSP 与 APO 需要避免重复；已挂载 APO 的麦克风应先旁路系统中的重复 EQ。

所有核心操作有按钮和键盘输入替代。曲线标记为理论 EQ 响应，支持选择/拖动与频段数字编辑。设置自动写本地草稿；本地 DSP 运行中修改立即作用于当前音频，系统 APO 仍保留预览后更新。

效果以卡片开关呈现，参数默认折叠；必要说明放在工具提示和诊断中。设备页显示驱动版本和两个端点状态，支持检查官网更新、重新下载、打开官方签名安装器。

测试与录音只在主动点击后打开麦克风；监听需指定物理输出并确认耳机。关闭窗口默认收进托盘并继续当前本地音频；托盘可打开、暂停/继续或明确退出，退出时停止并释放资源。APO 配置在程序退出后仍可能生效，移除单独管理。中文/英文切换只重建界面，不停止音频或改变参数。

本机原型保留在原目录，无复制旧 EXE 冒充重构，无驱动捆绑。真实麦克风、Discord 听感、一小时稳定性与跨显示器 DPI 由验证记录分别记载。
