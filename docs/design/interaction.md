# Mic Studio 0.1 设计与实施依据

石墨色原生 WPF 工作台，青绿为主要动作，琥珀色为待验证。左侧为七个页面，右侧内容始终可滚动；顶部选择设备、路线和旁路，底部独立显示采集与配置状态。窗口受屏幕工作区约束，紧凑宽度收起文字导航，卡片自动换行。

```text
┌ Mic Studio ───────── 设备 / 路线 / 旁路 ─────────────────────┐
│ 概览       让每一句，都清楚自然。              应用当前设置 │
│ 均衡器     [设备与状态]       [主动测量，停止时显示 —]     │
│ 效果链     [数字增益]         [输出衰减]                  │
│ 预设       [平直 / 自然 / 清晰 / 温暖]                    │
│ 设备连接   [主动录音 / 耳机回放 / 校准]                   │
│ 诊断设置   [清楚区分 APO 和本地 DSP 的操作说明]           │
└ 采集关闭 / 草稿已保存 / Discord 待验证 ───────────────────┘
```

APO 直接路线仅导出实际支持的增益与八段 EQ，动态及降噪在本地处理路线开放。APO 缺失仍可调音、保存草稿、测试本地处理和用已安装的 VB-CABLE 发送。切换路线停止采集，不把本地录音测量标为 APO 已生效。未经过人工通话确认的 Discord 状态始终为待验证。

信号顺序：输入数字增益 → 固定底噪频谱衰减（可选） → 八段 EQ → 压缩 → 轻柔扩展/噪声门（可选） → 创意处理（可选） → 输出补偿 → 采样峰值限幅。本地 DSP 与 APO 需要避免重复；已挂载 APO 的麦克风应先旁路系统中的重复 EQ。

所有核心操作有按钮和键盘输入替代。曲线标记为理论 EQ 响应，支持选择/拖动与频段数字编辑。设置自动写本地草稿；“应用”单独更新处理器或预览后写 APO。撤销/重做只影响草稿。内置预设不可覆盖，用户通过另存保存。

测试与录音只在主动点击后打开麦克风；监听需指定物理输出并确认耳机。关闭窗口停止所有本地音频会话。APO 配置在程序退出后仍可能生效，移除单独管理。

本机原型保留在原目录，无复制旧 EXE 冒充重构，无驱动捆绑。真实麦克风、Discord 听感、一小时稳定性与跨显示器 DPI 由验证记录分别记载。
