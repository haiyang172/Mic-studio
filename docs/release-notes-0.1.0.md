Windows 原生麦克风调节软件，面向任意可选择输入设备的录音、会议、直播和通话应用。

- 简洁界面：系统麦克风音量、数字增益、真实电平、八段 EQ、效果开关和个人预设；高级参数按需展开。
- 完整本地音频链：频谱降噪、压缩、柔和扩展器、采样峰值限幅及可选创意效果；本地录音、耳机回放、同源 RMS 匹配 A/B。
- 处理后输入选择 CABLE Output。捆绑官方 VB-CABLE 标准 Pack45，设备页支持检测、检查官网更新、重新下载和打开签名安装器。VB-CABLE 由 [VB-Audio](https://vb-cable.com) 提供，为 Donationware，欢迎[支持作者](https://vb-audio.com/Services/licensing.htm)。
- 提供自包含便携 ZIP 和当前用户安装器，无需开发工具。软件默认不打开麦克风、录音或监听。

自动功能测试 96 项、安装器安全与文件保留检查 40 项、WPF 控件事件检查 12 项通过；21 个实际窗口布局案例通过。真实虚拟线路增益 −6 dB 实测为 −6.000 dB。物理麦克风讲话听感、系统 APO 生效、外部软件接收、完整安装/升级/卸载、一小时稳定性和端到端延迟仍需实际验收。

这是 **0.1.0 预览版**。主程序与 Mic Studio 安装器尚未代码签名；捆绑的 VB-Audio 官方安装器已检查 Windows 签名。驱动安装由用户主动发起并确认 Windows UAC，不自动重启。

解压便携 ZIP 后运行 MicStudio.exe，或使用 MicStudio.Setup.exe。SHA256SUMS.txt 提供两份发行文件的完整性摘要。源码与实现细节见同版本标签和仓库文档。
