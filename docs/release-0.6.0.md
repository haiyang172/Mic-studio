# Mic Studio 0.6.0 开发预览 · 后台快捷操作

- 新增可配置后台快捷键：发送静音、效果开关、下一个预设、增益 ±1 dB、停止本地处理及按住说话。默认关闭，在设置页启用；支持冲突提示、清除和恢复默认。
- 主页面增加发送静音。按住说话只控制本地/CABLE 麦克风发送，耳机监听、处理电平和录音保持独立；松键或异常时关闭发送，需松开再按，停止状态不会自动开麦。
- 新增可选麦克风音量锁定，默认关闭。开启时记录所选设备当前系统音量，自己的滑条仍可调整目标；持续争抢或断线时暂停，切换麦克风后需重新开启。
- 记住快捷键、按住说话、发送静音和精确端点的音量锁定偏好；延续 A2「翡翠流线」图标、中英文和关闭到托盘。

默认快捷键均为 `Ctrl + Alt`：`M` 发送静音、`E` 效果、`P` 下一个预设、`↑ / ↓` 调增益、`S` 停止本地处理、`Space` 按住说话。快捷键适用于本地/CABLE 路线；系统麦克风静音仍是独立控制。

新增功能使用合成音频、模拟按键/端点与隔离界面检查，真实后台按键、睡眠唤醒、外部通话和长期运行仍需实际验收。完整 P3/P4/P5 的真实音频、可信 APO 签名部署、系统加载和完整安装验收继续保留。

下载 `MicStudio.Setup.exe` 或 `MicStudio-win-x64.zip`。本包不会注册未签名原生 APO，也不会自动重启系统音频服务。
