# Mic Studio 图标

Q 版角色佩戴薄荷绿耳机和麦克风，胸前 MS 徽章融合 Mic/Studio 标识；石墨色圆角底板与桌面界面一致。角色方向取代最初的纯字母标，保留 32 px 以上可辨认的面部、耳机和麦克风轮廓。

- `mic-studio.svg`：可编辑的矢量源文件，无字体或第三方图案依赖。
- `mic-studio.png`：512×512、透明外角，用于界面品牌及预览。
- `mic-studio.ico`：16、20、24、32、40、48、64、128、256 像素九个 32 位透明图层，用于 EXE、窗口及系统托盘。小于 32 像素时改用紧凑 MS 字母标，避免角色细节糊成一团；32 像素起保留角色轮廓，隐藏腮红、眼睛高光和胸前徽章等细节。

在 Windows 中运行 `scripts/Generate-Icon.ps1`，由 SVG 重新生成 PNG 和 ICO。渲染使用 WPF 矢量图形，无外部图片服务或图片处理依赖。
